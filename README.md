# OS Failure Lab

OS Failure Lab is a browser-based interactive platform that helps students understand Operating System concurrency problems like race conditions, deadlocks, starvation, and synchronization through simulations, thread execution timelines, visual graphs, and diagnostic reports.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- **Framework**: Next.js (App Router)
- **UI Library**: React 19
- **Language**: TypeScript
- **Styling**: Tailwind CSS
